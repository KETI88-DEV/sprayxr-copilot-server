## 결론

**RAG 근거로 해당 언어를 바로 생성하는 C 방식은 가능하지만, 이번 결과만으로 바로 배포할 수준은 아니다.** C는 B보다 잠정 수용 항목이 많았지만 A보다 많지는 않았다. 검색 근거의 관련성·적용 범위와 생성 프롬프트를 먼저 개선해야 한다. 이번 작업에서 배포 서비스·활성 언어·모델은 변경하지 않았다.

이 결과는 **5문항 × 7언어의 통제 실험이며, 배포 API 전체의 정확도가 아니다.** 배포 AgentPipeline의 전체 프롬프트·도구 루프·후처리는 재현하지 않았다. A/C의 시스템 지시와 생성 설정을 맞추고 C에 실제 검색 청크를 추가했으며, B는 이 조건으로 만든 한국어 원답을 번역했다. 따라서 “현행 서비스 정확도가 아래 점수” 또는 “RAG 자체가 무조건 나쁘다”는 결론은 낼 수 없다.

## 왜 실패했는가

1. **B는 한국어 원답 오류를 여러 언어로 전파했다.** Q02의 한국어 원답은 저도막이 아니라 가열 건조 도료 정의였다. Q04는 없는 A-1 적용 기준을 확인했다고 주장하며 합격 처리했다. 번역이 정확해도 원답이 틀리면 기술 답변은 실패다.
2. **검색 결과의 관련성 문제가 확인됐다.** Q02 상위 8개에는 도료 정의, 담색, 도막 성분, 가열 건조 도료 등은 있지만 저도막의 직접 정의가 없다. C의 일부 언어는 저도막을 적절히 설명했지만 한국어는 무관한 청크를 답으로 썼다.
3. **검색 수치가 적용 규격으로 둔갑했다.** Q04 근거에는 빈 검사표와 320 µm 예시가 있지만 A-1에 그 값을 적용한다는 연결 근거가 없다. C 중국어는 320 µm를 적용해 불합격·재도장을 지시했다. C 영어·우즈벡어는 기준을 요청해 수용됐다.
4. **재도장 조건의 적용 범위를 구별하지 못했다.** Q05의 특정 MIL-DTL-24441 관련 청크에 있는 7일·30일·4–8시간 조건을 제품 미지정 질문에 적용했다. C 미얀마어는 다른 청크의 저온/수분 노출 전 6/12시간 조건을 재도장 질문에 쓰고 인용 ID도 다르게 표시했다.
5. **번역 경로의 언어 이탈과 반복이 있었다.** B에는 한국어 그대로 또는 한국어 원문이 섞인 출력이 9개 있다. B의 한국어 Q03은 반복하다가 잘려 외국어 번역 6개를 실행하지 않았다. C에서도 근거 ID 반복·한국어 문서 복사·잘림이 발생했다.

A도 안전하지 않다. Q04에서 7언어 중 수용은 2개뿐이며, 중국어 75 µm·우즈벡어 120–160 µm·미얀마어 75 µm ±25% 등 없는 기준을 만들었다. **A의 총점이 높다는 이유로 RAG를 제거해서 배포하면 안 된다.**

베트남어는 A에서 5/5, C에서 3/5가 잠정 수용됐고 이번 B에서 한국어 반환은 없었다. 이는 이전 배포 번역 실패가 사라졌다는 증거가 아니다. 프롬프트·문장·토큰 상한이 다른 실험이며, 활성 언어는 그대로 유지했다.

## 완료 상태와 시간

HTTP 200 또는 `finish_reason=stop`은 정답을 뜻하지 않는다. 아래 시간은 **stop으로 끝난 항목만** 집계했으며, 틀린 답변도 포함한다. B는 한국어 생성과 번역을 합산한다. 실패·유보를 삭제한 정확도 점수가 아니며, 시간 표에서 제외된 실패 수를 함께 표시한다.

## 다음 진행 방향

- **C를 다음 개선 실험 후보로 유지하되 즉시 전환하지 않는다.** 한국어 답변을 만든 뒤 번역하는 의존성을 줄일 수 있으나 이번 수치만으로 품질 우위를 확정하지 못했다.
- 검색 관련성을 먼저 점검한다. 저도막 같은 현장 용어의 검색어 정규화·동의어, 중복 청크, 정의 문서 누락을 개선 대상으로 삼는다.
- 수치 판정은 해당 작업의 제품·구역·시방서 연결이 확인된 값만 사용한다. 연결 정보가 없으면 추가 정보를 요청한다. 일반 검색 예시를 작업별 판정 근거로 승격하지 않는다.
- 근거가 무관할 때 인용하지 않기, 요청 언어 유지, 반복·잘림 검출을 생성 프롬프트와 응답 검증에서 시험한다. 토큰 상한을 늘리기만 하면 반복이 길어질 수 있다.
- 개선용 질문과 별도로 보류 평가 세트를 구성하고 언어별 도장 전문가/원어민 검수를 받는다. 전문용어 출처 검증은 기존 [용어 문서](local_voice_multilingual_terminology.md)와 함께 계속한다.
- 동일 조건의 Gemma 결과는 없으므로 아직 모델 교체의 우열을 말할 수 없다. 검색·프롬프트 문제를 분리한 뒤 동일 근거·질문으로 후보 모델을 비교한다.

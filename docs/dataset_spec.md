### 2.2 실전모드 (참고, 범위 외)

### 2.4 레벨 지오메트리 (FBX)

`learning_mode_lv.1~10.fbx`, 바이너리 FBX 7400. 정점·폴리곤·법선·UV 전부 파싱된다(lv1 16v/28f ~ lv9 384v/764f).
CSV의 `Ray Texture UV`를 2048로 나눈 값이 FBX UV 범위 안에 정확히 들어가 **UV 공간이 정합한다**.
단 머티리얼·서브메시가 0개인 단일 메시라 **region 구획이 내장돼 있지 않다**.

## 3. 원본 스키마 (CSV 171컬럼)

원본이 정본이다. 0.3.0 JSON export는 Ray 컬럼을 버린 손실 변환이므로 학습에 쓰지 않는다.

| 컬럼 | 내용 |
|---|---|
| 1~3 | 인덱스, 시간(초), 분사(On/Off) |
| 4~39 | 오브젝트 6종(한길숏건·한길폴건·반도숏건·반도폴건·플래쉬·카메라) × Position XYZ + Rotation XYZ |
| 40~159 | 관절 20개 × Position XYZ + Rotation XYZ |
| 160~165 | Record, Distance/Speed (Input), Distance/Speed (Real), Model Input Data |
| 166~171 | Ray point X/Y/Z, Ray Texture Map Number, Ray Texture UV X/Y |

주의점:
- 헤더에 BOM이 있고 `" Ray Point Y"`, `" Ray Point Z"`는 **선행 공백**을 포함한다. 조회 전 strip 필수.
- 관절 `Position` 컬럼은 **프레임 불변 상수(bind offset)** 다. 월드 관절 좌표가 아니다. Pelvis만 이동한다.
- 미사용 건은 `(-694, 701, 698)` 주차 좌표에 고정된다. 활성 건은 위치 분산으로 판별한다.
- `Model Input Data`는 `thick@` 뒤 13필드: Viscosity, Nozzle, GunSpeed, SetPressure, GunDistance, PushTime, SVR, ThinnerDilutionLaw, Temperature, MakerName, H1, H2, H3.
- 사이드카 `.txt`에 VarnishID / VarnishColorID / NozzleID / Month / Pressure / ThinnerRate / Model.

## 4. 데이터 품질 — 학습 전 반드시 처리할 것

### 4.1 오일러 각 0/360 wrap (해결 가능)

인접 프레임 359.9° 점프가 다수 발생한다. 산술 통계를 쓰면 결과가 무의미해진다.

| 관절축 | 산술 std | 순환 std |
|---|---|---|
| Spine X | 143.5° | 5.5° |
| Chest X | 163.9° | 14.1° |
| RightUpperArm X | 159.9° | 25.1° |

숙련자는 실제로 매우 일관적이며, 큰 산포는 전부 인공물이었다. **순환/구면 통계 필수.**

### 4.2 3-DOF 팔 관절의 ~180° 불연속 (미해결, REQ-15)

분사 프레임 34,460개 기준 쿼터니언 측지 점프(>30°/11.1 ms) 발생률:

| 관절 | 발생률 | step | spike | median 필터 후 |
|---|---|---|---|---|
| Spine | 0.11% | 38 | 1 | 47 |
| Chest | 0.08% | 29 | 0 | 31 |
| RightShoulder | **1.36%** | 389 | 79 | 422 |
| RightUpperArm | **1.84%** | 468 | 166 | 614 |
| RightForeArm | 0.14% | 48 | 1 | 45 |
| RightHand | **1.09%** | 338 | 39 | 377 |

3-DOF 볼조인트에만 나타나고 1-DOF 힌지(전완)는 깨끗하다. 대부분 되돌아오지 않는 step이며 **median 필터로 제거되지 않는다.**
오일러 순서 12개 규약 브루트포스로도 해소되지 않았다(전 규약에서 최대 점프 179.4° 동일) — 순서 artifact가 아니라 데이터 성질이다.

대응: 쿼터니언 측지거리 + 측지 상위 10% 트리밍 + 비물리 속도 프레임 사전 마스킹.

### 4.3 좌표계 분리 (미해결, REQ-14)

```
|카메라 − 한길숏건| = 0.716 m   ← 팔 길이, 정상
|카메라 − Pelvis|   = 5.155 m   ← 인체에서 불가능
축별 (카메라−Pelvis) std = 0.140 / 0.169 / 0.232 m   ← 상수 평행이동 아님
축별 상관 = +0.243 / +0.182 / +0.389                 ← 약함
```

건·카메라·플래쉬·Ray 충돌점은 하나의 월드 좌표계, 스켈레톤은 별도 리그 공간이다.
스켈레톤끼리 비교하는 현 범위에서는 무관하다.

### 4.4 레이 미적중 프레임

분사 중인데 표면에 닿지 않는 프레임이 학습모드 기준 11~25%다. 자세 채점에서 처리 규칙을 **숫자를 보기 전에** 고정해야 한다.
짧은 미적중 구간(스트로크 전환 lead-in/out)은 포함하고, 긴 구간이나 burst 경계 미적중은 조준 실패로 분리 집계한다.

## 5. 모델별 필요 데이터

### 5.1 자세 유사도·교정

| 필요 | 출처 | 상태 |
|---|---|---|
| 관절 로컬 회전 시계열 | CSV 40~159 | 확보 |
| 골격 링크 길이(관절 가중치용) | bind offset 상수 | 확보 |
| burst 분할(자세와 무관한 정렬 기준) | `분사` On/Off | 확보, 1,825개 |
| 정렬 위상 φ∈[0,1] | burst 내 선형 리샘플 | 파생 |
| 회전 순서 | — | **미확보(REQ-05)** — 유사도는 산출 가능, 해부학적 교정 지시문은 불가 |
| hierarchy | — | **미확보(REQ-08)** |
| 훈련생 코호트 | — | **미확보(REQ-16)** — 현재 "기존 자세"는 숙련자 본인의 편차 프레임 |

자세 정렬을 자세 특징 위에서 DTW로 잡으면 안 된다. DTW가 보고할 거리를 스스로 최소화해 낙관 편향이 생기고,
"이 순간 팔꿈치가 틀렸다"는 교정 의미론이 무너진다. 정렬 신호는 burst 위상 또는 UV 경로처럼 **자세에 외생적**이어야 한다.

### 5.2 경로·순서

| 필요 | 출처 | 상태 |
|---|---|---|
| 작업자 동선 | 카메라 월드 궤적(XZ 투영) | 확보 — 스켈레톤 대신 쓰는 유일하게 깨끗한 위치 신호 |
| 작업면 경로 | Ray UV / 2048 정규화 | 확보 |
| 작업면(region) 라벨 | — | **미저작** — FBX 지오메트리는 있으나 UV 구획을 직접 만들어야 한다(미계상 공수) |

학습모드는 레벨당 맵이 1개라 맵 번호로는 region이 1개다. 순서 신호는 **UV 공간 내 도포 순서**에서 나온다.

### 5.3 도막 결과 (외부 검증용)

세션별 `Map01_..._Height.png` → µm. burst 단위 귀속 가능 여부는 REQ-11 확인 후 결정한다.

## 6. 파이프라인

```
원본 CSV (+ .txt)                     data/sources/professionals/전형기
  │  trainer/scripts/simulator_csv.py   벤더 CSV 방언 → 프레임
  │  trainer/scripts/session_csv.py     프레임 → 세션·시퀀스 JSON (surface_hit 보존)
  ▼
세션 인덱스 + 시퀀스 문서 (0.4.0)
  │  trainer/scripts/parse_session.py   검증·활성건 판별·degraded 리포트
  │  trainer/scripts/build_expert_reference.py
  ▼
숙련자 참조 아티팩트 (자세 분포 + region flow)
```

`session_csv.py`는 벤더 자체 export와 시퀀스 frame_count·spray_count가 완전히 일치함을 확인했다.
`build_expert_reference.py`는 현재 오일러 각에 **산술** 평균/표준편차를 쓰므로 4.1에 의해 무효다. 순환/구면 통계로 교체해야 한다.

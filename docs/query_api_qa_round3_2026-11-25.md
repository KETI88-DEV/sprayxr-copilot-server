완료 리포트에는 과도막 구역 수 비율과 과도막 픽셀 면적 비율을 각각 표시합니다. 분사 평균 이격거리의 중앙값을 완료 제출 평균과 구별하고, 새 세션에는 다른 세션의 확정 점수를 가져오지 않습니다. 자세 채점 건수에도 저장된 분사 건수를 혼용하지 않습니다.

## 시험 조건과 판정

- 분사 전에는 시퀀스가 없습니다. 진행 중인 합성 세션은 2구역 진행률 약 84.84%, 이동 기준을 충족한 세션은 85.03%로 다음 3구역을 안내합니다. 후자의 목표 두께 도달 면적은 50%입니다. 두 지표를 각각 확인했습니다. 리플레이 질문은 완료 리포트 미수집 상태에서 실행했습니다.
- 기준 순서를 묻는 질문은 학습모드 2의 등록 자료와 대조했습니다. 스프레이의 기준 순서는 2 → 3 → 1이며, 블라스팅의 기준 순서는 1 → 2 → 3입니다.
- 각 응답의 사실, 질문 의도, 자료가 비어 있을 때의 안내를 예상 동작과 비교했습니다. 적절하게 답변을 보류하거나 잘못된 요청에 계약대로 422를 응답한 경우도 통과입니다.
- **통과**는 필요한 사실과 조건을 충족한 경우입니다. **부분 통과**는 핵심 사실 일부를 답했으나 조건, 근거 또는 다음 행동이 빠진 경우입니다. **실패**는 의미를 잘못 읽거나 확인 가능한 사실을 빠뜨리거나 없는 값을 제시한 경우입니다.

# 다국어 답변 3방식 비교 조건

2026-10-06. 대상은 기존 5개 질문 × 7개 언어, 총 35개 질문이다. 모델은 Spark의 `qwen36-27b-shipcoat-v6-1-bf16`로 고정한다. 아래 기준은 추가 RAG 응답 생성 전에 작성했다.

## 비교 방법

| 방법 | 처리 | 평가할 결과 |
|---|---|---|
| A | RAG 없이 각 언어 질문에 직접 답변 | 앞서 저장한 실제 응답 35건 재사용 |
| B | 한국어 질문으로 RAG → 한국어 답변 → 대상 언어 번역 | 한국어 생성 5건과 번역 30건. 한국어 결과는 C와 공유 |
| C | 같은 RAG 근거 + 원어 질문 → 해당 언어로 직접 답변 | 한국어 5건은 B와 공유, 외국어 30건 추가 생성 |

한국어에서 B와 C는 같은 방법이므로 응답을 공유한다. 비교 행은 105개이며 A의 기존 35호출과 이번 신규 65호출로 구성된다. 한국어 답변을 공유하는 것은 B에서 번역 언어별로 한국어 답변이 달라지는 변수를 제거하기 위한 것이다.

## 통제 조건과 차이

- 질문은 기존 예시 문서의 동일 문장이다. 기대 답변은 생성 모델에 주지 않는다.
- B/C 검색에는 한국어 정본 질문을 사용한다. 입력 번역과 다국어 검색의 오류는 이번 비교 범위에서 제외한다.
- Spark의 실제 인덱스·BGE-M3·리랭커로 질문당 상위 8개 청크를 검색하고 고정한다. 추가 GPU 상주 모델 없이 CPU에서 검색했다. 해당 근거의 SHA256이 B/C의 모든 언어에서 같아야 한다.
- A/C는 같은 시스템 지시·질문·생성 설정을 사용한다. C의 사용자 메시지에 검색 청크만 추가한다. 한국어 답변 생성도 같은 한국어 시스템 지시를 사용한다.
- 이는 **고정 근거를 넣는 통제 실험**이다. 배포 AgentPipeline의 전체 시스템 프롬프트·도구 루프·응답 정규화를 재현하지 않으므로 B를 현행 배포 API의 정확도, C를 배포 완료된 새 경로의 정확도로 해석하지 않는다.
- 생성 설정은 temperature=0, top_p=1, top_k=-1, repetition_penalty=1.0, max_tokens=192, enable_thinking=false다. 잘림·HTTP 오류·다른 언어 출력도 삭제하거나 재시도해 숨기지 않는다.
- B 번역은 배포 번역 프롬프트·용어집과 영어/중국어 번역 예시를 사용한다. 베트남어는 이전 시험의 같은 예시를 재사용한다. 우즈벡어·미얀마어·네팔어는 검증된 예시가 없으므로 예시 없이 같은 번역 지시를 사용한다. 이 세 언어는 실험용 확장이다.
- B도 생성 상한을 192로 맞춘다. 배포 API의 번역 상한 1024와 다르므로 배포 API 자체의 정답률을 측정하는 시험은 아니다. 응답 필터가 실패를 가리기 전의 모델 출력을 비교한다.
- 지연시간은 A/C의 생성 HTTP 시간, B의 한국어 생성+번역 HTTP 시간이다. 이미 고정한 검색 시간과 입력 번역·음성 인식은 제외한다. B의 한국어 생성 시간은 캐시로 생략하지 않고 합산한다. 서로 다른 시점·한 번씩의 요청이므로 p95/SLA로 해석하지 않는다.

## 질문별 기술 내용 판정 기준

각 응답에 `기술 내용 충족`, `요청 언어 준수`, `주요 오류`, `검토 확신도`를 기록한다. 두 조건을 모두 충족한 비율을 잠정 수용률로 제시한다. AI 검토이며 원어민·도장 전문가의 독립 검수를 완료한 점수가 아니다.

| 질문 | 기술 내용 충족 조건 | 실패 조건 |
|---|---|---|
| Q01 DFT | 건조된 도막의 두께라는 핵심 정의 | 건조 시간·젖은 두께·사용량 등과 혼동, 다른 주요 사실 오류 |
| Q02 저도막 | 요구되는 두께보다 부족한 상태라는 설명 | 도막 과다와 반대로 설명, 무관한 개념으로 대체, 근거 없는 공통 두께 기준 |
| Q03 표면처리 | 도장 전 표면 준비·청정/오염 제거와 도장 적합성의 설명 | 무관한 작업, 본질적인 처리 목적 오류 |
| Q04 80 µm | 적용 규격·검사 기준이 없어 합부를 확정할 수 없다고 설명 | 임의 기준·허용오차를 도입해 판정, 기준 없이 통상 합격/불합격이라고 답변 |
| Q05 재도장 | 제품·건조 조건/환경·제조사 지침/TDS에 따라 간격을 확인해야 한다고 설명 | 현 정보에 적용할 수 없는 시간을 단정, DFT를 시간으로 혼동, 근거 없는 특정 범위로 안내 |

Q04의 일반 문서 속 수치는 요청의 A-1 구역에 적용되는 규격이라고 확인된 값이 아니다. 검색 문서에 숫자가 있다는 이유만으로 해당 구역 판정에 전용하면 실패다. Q05도 제품명이 없으므로 특정 제품의 간격을 현재 질문의 답으로 단정하면 실패다.

언어 준수는 요청 언어로 실질적인 답변이 작성됐는지 별도로 판정한다. 기술 내용이 맞아도 한국어를 다른 언어의 응답으로 내보내면 종합 수용에서는 실패다. 미얀마어·네팔어 등 검토가 불확실한 문장은 별도 유보 표시하고 전문가 확인 없이 확정 정답으로 세지 않는다.

표본은 언어별 5문항에 불과하다. 한 문항이 20%p이므로 언어 전반의 정확도 또는 통계적 우위를 입증하지 않는다. 정식 배포 확대·모델 교체의 단독 승인 근거로 사용하지 않는다.

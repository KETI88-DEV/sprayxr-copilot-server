# 훈련 중 Query API 변형 질의 검증

2026-11-25에 가상 훈련 세션을 구성하고 동일한 질문을 수정 전후 API로 호출했습니다. 처음 권장하는 구역, 최근 기록에서 확인된 구역, 현재 작업을 마칠 수 있는지를 응답의 문장과 기계 판독용 값으로 확인했습니다.

- 수정 전 35건 중 통과 12건, 부분 통과 8건, 실패 15건
- 수정 후 35건 중 통과 35건
- 부분 통과는 구역 번호가 맞아도 해당 세션의 저장 기록을 조회하지 않거나, 요청한 도막 상한을 직접 답하지 못한 경우를 포함합니다.
- 2구역의 진행률이 84.84%이면 보완을 안내하고, 85.03%이면 3구역 이동을 안내합니다. 목표 도달 면적과 이동 판정 진행률은 공식 Zone 안에서 각각 계산합니다.
- 도막 정상 범위는 세션별 저장 설정입니다. 실제 평균 두께는 누적 히트맵의 도포부에서 보정해 계산한 값입니다.
- 시험 데이터는 모두 합성 데이터를 사용했습니다. 현장 시방 수치와 시뮬레이터 클라이언트의 색상 해석은 이번 합격 집계 범위에서 제외했습니다.

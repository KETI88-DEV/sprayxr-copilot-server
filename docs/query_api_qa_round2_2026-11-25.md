# Query API 새 질문 100개 시험

2026-11-25 · 최초 시험 v3.15.12 · 교정 검증 v3.15.13

이전 100문항과 질문 의도가 겹치지 않도록 새 문항을 작성했습니다. 현장 기술과 매뉴얼 30개, 훈련 상태와 완료 리포트 25개, 다국어와 용어집 25개, 시뮬레이터와 API 계약 20개입니다. 마지막 영역의 4개는 공백 질문, 미지원 답변 모드, 검색 값과 언어 코드에 대한 HTTP 422 계약 검사입니다.

최초 시험은 메인 서버에서 전용 QA 계정으로 호출했습니다. 훈련 질문에는 분사 전, 이동 기준 미달, 이동 기준 충족, 블라스팅 시작, 종료 리포트의 합성 세션을 사용했습니다. 리포트에는 Zone 방문 2 → 1 → 2 → 3과 Map 1의 세 구역 도막이 들어 있습니다. 자세를 판정할 수 있는 관절 자료는 없는 상태입니다.

| 영역 | 최초 통과 | 최초 부분 통과 | 최초 실패 | 교정 재시험 |
| --- | ---: | ---: | ---: | ---: |
| 현장 기술·매뉴얼 | 6 | 12 | 12 | 24 |
| 훈련 상태·완료 리포트 | 3 | 10 | 12 | 22 |
| 다국어·용어집 | 15 | 4 | 6 | 10 |
| 시뮬레이터·API 계약 | 7 | 8 | 5 | 13 |
| **합계** | **31** | **34** | **35** | **69** |

최초 통과 31개는 교정 대상에서 제외했습니다. 앞 질문이 필요한 후속 질문은 동일 대화에 필요한 문맥을 제공했습니다. 각 문항의 최초 응답과 배포 전 실제 재시험 응답을 홈의 v3.15.13 업데이트에 기록했습니다. 이전 시험 100개는 v3.15.12 업데이트에서 확인할 수 있습니다.

재시험에서 통과한 문항은 제목 옆에 **교정 완료**를 표시합니다. 최초 답변과 교정 후 답변을 펼쳐 비교할 수 있으며, 통과 판정을 받은 답변에 녹색 테두리를 표시합니다.

배포 전 재시험에서는 교정 대상 69개 모두 HTTP 200을 반환했고 판정 기준을 충족했습니다. 이격거리와 도막 수치는 해당 시퀀스·구역·리포트의 근거를 같이 표시했습니다. 다국어 답변은 검증된 용어와 수치·단위·조건을 보존하는지 확인했습니다.

v3.15.13을 배포한 뒤 메인·TSB에서 교정 대상 69개를 각각 다시 호출했습니다. 두 서버 모두 69개가 통과했습니다. 메인 응답은 69개, TSB 응답은 67개의 본문이 배포 전 답변과 일치했습니다. TSB의 접지 안내와 영어 재도장 안내 2개는 표현이 달랐으며 각각의 근거와 판정 기준을 충족했습니다.

메인 데스크톱과 TSB 모바일에서 새 질문 100개와 교정 완료 표시 69개를 확인했습니다. 이전 시험의 문항에도 교정 완료 표시가 적용됐습니다. 배포 소스의 전체 회귀 테스트는 통과 5,872개, 기존 실패 185개, 건너뜀 42개였습니다.

# 작업 자세 비교 평가 통합 설계

## 1. 목적

기존 `/motion-viewer`를 전문가 동작 재생 도구에서 작업자와 전문가의 작업 자세를 비교·평가하는 주 화면으로 확장한다. 사용자는 실제 피도면, Zone, 착탄 경로, 작업자 자세, 전형기 반장의 기준 자세와 한 가지 핵심 교정 지시를 같은 시점과 같은 좌표계에서 확인할 수 있어야 한다.

이 화면의 우선 질문은 다음 세 가지다.

1. 작업자가 어느 Zone의 어떤 시퀀스를 수행했는가.
2. 전문가 기준과 비교했을 때 자세가 어떻게 다른가.
3. 지금 무엇을 어떻게 고쳐야 하는가.

## 2. 설계 원칙

- 공식 자세 결과는 운영 엔진 `POST /pose_estimation/sequence`의 결과를 정본으로 사용한다.
- `trainer/pose_lab`의 기준 동작 선택, 3D 표현, 교정 화살표 및 메시 배치 코드를 재사용하되 별도 화면을 iframe으로 삽입하지 않는다.
- 자세 평가의 외부 단위는 TSB의 `sequence_id`로 유지한다. 엔진이 시퀀스 내부를 나눈 스트로크·패스는 세부 단위로만 표시한다.
- Zone 평가는 Zone 전체를 하나의 자세로 다시 채점하지 않는다. Zone에 속한 시퀀스·스트로크 결과를 집계한다.
- 스켈레톤은 추정 시각화이고, 머리(HMD)·오른손(건)·왼손(플래시) 실측 위치가 평가 근거임을 UI에서 구분한다.
- 한 화면에서 작업자가 실행할 교정은 중요도 1위 한 건만 강조한다. 나머지는 상세 분석에서만 제공한다.
- 검증되지 않은 모델 정렬이나 부족한 입력을 그럴듯한 값으로 보완하지 않는다.

## 3. 피도면 모델과 좌표 정렬

학습모드별 실제 FBX 모델은 `trainer/scripts/level_mesh.py`로 읽고 `trainer/data/level_alignment.json`의 변환을 적용한다. 변환은 `Ray Texture UV`와 실제 `Ray Point`의 대응으로 계산된 것이며, 위치·회전·스케일·손대칭 검증을 통과한 항목만 사용한다.

- 기본 모델 경로: `/data/sources/modelings`
- 검증된 정렬: 학습모드 1, 3~10
- 미검증 정렬: 학습모드 2
- FBX 파일과 정렬 메타데이터는 Git 코드와 분리된 배포 데이터로 취급한다.

표현 우선순위는 다음과 같다.

1. FBX와 검증된 정렬이 모두 있으면 실제 메시를 기본 피도면으로 표시한다.
2. 모델이 없거나 정렬이 미검증이면 현재 Ray Point 기반 Zone 표면으로 대체한다.
3. Ray Point 점군은 FBX 사용 여부와 무관하게 실측 착탄 근거 레이어로 유지한다.

피도면은 중성의 어두운 반투명 재질로 그리고 현재 Zone만 라벨링 문서의 색으로 강조한다. 착탄점, 작업 궤적 및 교정 화살표가 모델에 가리지 않도록 깊이와 투명도를 조정한다.

## 4. 화면 구성

페이지 제목은 `작업 자세 비교 평가`로 변경한다. 기본 탭은 자세 비교다.

### 4.1 왼쪽 선택·재생 패널

- 훈련 종류: 스프레이/블라스팅
- 학습모드
- 작업자
- 세션
- 시퀀스와 현재 Zone
- 재생/일시정지/처음으로
- 진행 위치와 0.25~3배 재생 속도

전문가 기준 파일은 사용자가 직접 선택하지 않는다. 같은 학습모드와 유사 동작 조건에 맞는 전형기 기준을 자동 선택하고, 선정 이유만 상세 영역에 표시한다.

### 4.2 중앙 뷰

중앙에는 공통 타임라인을 공유하는 탭을 둔다.

- `자세 비교`: 기본 탭. 실제 피도면 위에 작업자, 전문가, 교정 후 예상 자세를 표시한다.
- `도장 경로·Zone`: 현재 모션뷰어의 Zone 면, 점군, 표준 도장 패턴 및 선택 기록 궤적을 표시한다.
- `도막 분포`: 별도 도막 시각화가 구현되는 시점에 추가하며 이번 통합 범위에는 포함하지 않는다.

자세 비교 색상은 다음과 같이 고정한다.

- 작업자: 파랑
- 전문가 기준: 초록
- 교정 후 예상 자세: 노란 점선 또는 반투명 윤곽
- 실제 착탄·도장 궤적: 주황
- 핵심 교정 화살표: 노랑

머리·양손 실측 마커와 궤적은 불투명하게, 추정 스켈레톤은 반투명하게 표시한다. 현재 교정 대상 부위와 화살표만 강하게 강조한다.

### 4.3 공통 타임라인

타임라인에는 Zone 색상 구간, 시퀀스 경계, 내부 스트로크 경계와 자세 경고 마커를 표시한다. 경고 마커를 누르면 해당 순간으로 이동하고 재생을 멈춘다. 중앙의 두 탭은 같은 재생 위치를 유지한다.

### 4.4 오른쪽 평가 패널

기본 화면에는 다음 항목만 노출한다.

- 현재 위치: `Zone 3 · SEQ-012 · 스트로크 2/4`
- 종합 상태: 전문가 기준과 유사/보완 필요/평가 불가
- 자세 유사도와 전문가 분포 내 위치
- 가장 큰 위치 편차
- `지금 고칠 한 가지` 교정 문장
- 평가 신뢰도와 기준 데이터 상태
- Zone별 요약과 가장 낮은 시퀀스

원시 σ, UV 입도, 리샘플 수, 관절 각도 전체 표, 동일·분리 개선율 등 연구용 수치는 `연구·검증 상세`에 접어 둔다.

## 5. 데이터 흐름

### 5.1 TSB 세션 데이터

1. 저장된 세션에서 `session_id`와 `sequence_id`로 시퀀스 원문을 읽는다.
2. 운영 자세 엔진에 동일 원문을 전달한다.
3. `analysis_status`, `similarity_score`, `expert_percentile`, `corrections`, 입력 품질과 스트로크 결과를 받는다.
4. 프레임의 Zone ID로 시퀀스와 스트로크를 Zone에 연결한다.
5. 모델, 궤적, 자세 레이어와 평가 결과를 하나의 뷰 모델로 반환한다.

### 5.2 과거 CSV 데이터

1. 기존 `CsvPassSource`와 패스 세분화 규칙을 재사용한다.
2. CSV 세션에 안정적인 화면용 시퀀스 식별자를 부여한다.
3. `pose_lab /api/diagnose`가 사용하는 배포 채점 경로와 같은 방식으로 평가한다.
4. Zone ID가 있는 행을 기준으로 패스를 Zone에 연결한다. 한 패스가 여러 Zone을 포함하면 연속 구간을 분리하고 임의 다수결로 합치지 않는다.

### 5.3 Zone 집계

Zone별로 다음만 집계한다.

- 평가 가능한 시퀀스·스트로크 수
- 자세 유사도 중앙값
- 최저 결과와 해당 시퀀스
- 가장 반복된 핵심 교정
- 입력 품질이 낮아 제외된 건수

## 6. 서버 경계

기존의 거대한 `motion_viewer.py` HTML 문자열에 pose_lab 전체를 복사하지 않는다. 다음 책임을 분리한다.

- `motion_viewer.py`: 라우팅, 카탈로그, 기존 전문가 경로 데이터
- 자세 평가 어댑터: 저장 시퀀스/CSV를 공식 엔진 입력으로 변환하고 결과를 화면 계약으로 투영
- 메시 제공기: FBX와 검증된 정렬을 읽어 정점·삼각형·상태를 제공
- Zone 집계기: 시퀀스·스트로크 결과를 Zone 통계로 집계
- 정적 UI 모듈: 레이아웃, 공통 타임라인, 피도면·자세 렌더링, 평가 패널

화면 API는 내부 MCP 원문을 그대로 노출하지 않고 필요한 필드만 반환한다. 공식 점수와 교정 문구를 브라우저에서 다시 계산하지 않는다.

## 7. 오류와 대체 표시

- FBX 없음: Ray Point 기반 표면 사용, `설계 모델 없음` 상태 표시
- 정렬 미검증: FBX를 표시하지 않고 `피도면 정렬 미검증` 표시
- 자세 기준 없음: 궤적 재생은 유지하고 평가를 `평가 불가`로 표시
- 일부 관절 누락: 엔진의 입력 품질과 제외 관절을 표시하고 임의 보간으로 점수를 만들지 않음
- Zone ID 없음: 시퀀스 평가는 유지하되 Zone 집계에서는 제외
- 엔진 장애: 기존 궤적·모션 재생은 유지하고 자세 패널만 실패 상태로 격리

## 8. 이번 통합에서 제외할 기능

- 모델 파일을 Git 저장소에 직접 커밋
- 실전모드 모델 정렬을 추정으로 생성
- 도막 높이맵 3D 표현
- 작업자에게 여러 교정을 동시에 강조
- 관절 각도만으로 공식 점수를 다시 계산
- pose_lab 화면을 iframe으로 포함
- 기존 외부 TSB 요청 JSON 변경

## 9. 검증 기준

- 검증된 각 학습모드에서 FBX 표면과 Ray Point가 기존 정렬 품질 기준을 유지한다.
- 학습모드 2는 미검증 메시를 표시하지 않는다.
- 같은 시퀀스의 UI 결과와 `pose_recomm` 결과가 점수·상태·핵심 교정에서 일치한다.
- 작업자/전문가/예상 자세의 타임라인이 같은 시점에서 동기화된다.
- Zone을 선택하면 해당 Zone의 시퀀스와 통계만 강조된다.
- 스켈레톤 표시를 끄거나 렌더러가 실패해도 점수와 교정 결과가 바뀌지 않는다.
- 1200px 이하 화면에서도 평가 패널을 숨기지 않고 중앙 아래로 재배치한다.
- 모델·기준 데이터·Zone ID 누락 상태를 각각 구분해 표시한다.

## 10. 완료 조건

사용자가 한 화면에서 작업자 세션을 선택하고, 실제 피도면의 현재 Zone에서 작업자와 전형기 반장의 자세를 동기화해 비교하며, 문제 지점과 가장 중요한 교정 한 건을 확인할 수 있다. 같은 시퀀스에 대한 화면 결과와 Co-Pilot `pose_recomm` 결과가 일치해야 한다.

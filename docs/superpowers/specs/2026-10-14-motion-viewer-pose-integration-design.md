# 모션뷰어·작업 자세 비교 단일 화면 통합 설계

## 1. 목적

기존 `/motion-viewer`의 전형기 반장 모션·도장 경로·Zone 재생 기능과 `trainer/pose_lab`의 작업자 자세 비교 기능을 하나의 선택 흐름, 하나의 3D 화면, 하나의 타임라인으로 통합한다. 사용자는 훈련모드와 기록을 선택해 도장 경로를 재생하면서 같은 시점의 작업자 자세, 자동 선정된 전문가 기준, 핵심 교정을 동시에 확인할 수 있어야 한다.

## 2. 기준과 제약

- 공식 자세 점수와 교정은 운영 엔진 `POST /pose_estimation/sequence` 결과를 정본으로 사용한다.
- 김미진 선임의 `origin/feat/pose-recomm` 최신 버전을 먼저 병합하고, 기준 자세 선정·메시 정렬·교정 방향 표시 코드를 재사용한다.
- 기존 TSB 요청 JSON은 변경하지 않는다.
- 기존 전문가 CSV 선택·모션 재생·Zone·Ray Point·표준 도장 패턴 기능은 유지한다.
- 자세 비교와 도장 경로를 탭으로 분리하지 않는다.
- 검증되지 않은 모델 정렬이나 없는 전문가 자세를 임의로 합성하지 않는다.
- 모델링 파일은 Git에 넣지 않고 `/data/sources/modelings` 읽기 전용 마운트를 사용한다.

## 3. 통합 선택 흐름

왼쪽 선택 영역은 다음 순서로 통일한다.

1. 훈련 종류: 스프레이/블라스팅
2. 훈련모드(레벨): 1~10
3. 작업자: 전형기 반장 또는 평가 대상 작업자
4. 기록: 전문가 CSV 또는 작업자 세션
5. 시퀀스: 작업자 세션을 선택한 경우 선택 가능

전형기 반장을 선택하면 기존처럼 해당 모드의 CSV 기록을 직접 고른다. 일반 작업자를 선택하면 작업자 세션과 시퀀스를 고르고, 같은 모드와 동작 조건에 맞는 전형기 기준 기록은 자세 엔진의 기준 선정 결과를 따라 자동 선택한다. 자동 선정 근거는 상세 정보에 표시하되 사용자가 임의 기준을 골라 공식 점수를 바꾸게 하지 않는다.

TSB 저장 세션과 전문가 CSV는 서로 다른 자료원이므로 내부 식별자는 구분하되 화면에서는 동일한 `기록` 개념으로 표현한다. 자료원 전환 시 이전 비동기 요청 결과가 새 선택을 덮어쓰지 않도록 generation token으로 취소한다.

## 4. 단일 3D 화면

중앙 화면은 다음 레이어를 동시에 그린다.

- 검증된 피도면 FBX 또는 Ray Point 기반 대체 표면
- Zone 면, 라벨, 전문가 표준 도장 패턴
- 선택 기록의 도장 경로와 현재 착탄 위치
- 작업자 자세와 머리·양손 실측 위치: 파랑
- 자동 선정된 전형기 기준 자세: 초록
- 핵심 교정 목표와 방향 화살표: 노랑
- 작업자/전문가 분사 경로: 주황/노랑

레이어는 `피도면·Zone`, `도장 경로`, `작업자 자세`, `전문가 자세`, `교정 표시` 체크박스로 개별 표시를 조절한다. 기본값은 판단에 필요한 레이어만 켜며, 정보가 겹쳐 읽기 어려운 경우 스켈레톤 투명도를 낮추고 머리·양손 실측 마커와 핵심 교정만 불투명하게 유지한다.

기존 자세비교/도장경로 탭과 자세 전용 캔버스·타임라인은 제거한다. 두 기능은 동일 캔버스의 레이어가 된다.

## 5. 재생과 시간 동기화

재생 위치는 초 단위 공통 playhead 하나로 관리한다. 전문가 CSV, 작업자 시퀀스, 도장 경로, 자세 레이어는 각자의 타임스탬프에서 공통 playhead와 가장 가까운 프레임을 선택한다. 프레임 배열 인덱스를 서로 직접 대응시키지 않는다.

재생, 일시정지, 처음으로, 0.25~3배 속도, 진행 슬라이더는 하나만 둔다. 시퀀스 변경, Zone 선택, 교정 위치 이동 시 같은 공통 playhead를 갱신한다. 작업자 시퀀스가 전문가 기록보다 짧거나 긴 경우 0~1 진행률 보간을 사용하되 화면에 `상대 시간 정렬` 상태를 표시한다.

## 6. Unity식 카메라와 기즈모

회전 중심은 월드 원점에 고정하지 않는다. 데이터를 불러올 때 다음 우선순위로 가시 객체의 경계 상자와 중심점을 계산한다.

1. 표시 가능한 피도면 메시
2. Ray Point·Zone 표면
3. 작업자와 전문가의 머리·양손·스켈레톤 궤적

초기 orbit target은 이 중심점, 초기 거리는 경계 상자를 화면에 맞추는 거리로 설정한다. 따라서 객체가 원점에서 떨어져 있어도 객체 중심으로 자연스럽게 회전한다.

조작은 다음과 같다.

- 좌클릭 드래그: 현재 target 중심 orbit
- 휠 클릭 드래그: 카메라 평면 기준 pan, target도 함께 이동
- 휠 스크롤: target 방향 dolly/zoom
- 우클릭 드래그: 시선 방향 회전
- 우클릭 유지 + `W/A/S/D`: 전후좌우 이동
- 우클릭 유지 + `Q/E`: 상하 이동
- `F`: 현재 표시 객체에 초점 맞춤

뷰 상단에는 X/Y/Z 축 기즈모와 홈 버튼을 둔다. 축을 누르면 정면/측면/평면 직교 시점으로 전환하고, 홈 버튼은 현재 데이터의 초기 중심·거리·회전으로 복귀한다. 새 기록을 불러오면 초기 카메라 스냅샷을 다시 계산한다.

## 7. 정보 구조와 중복 제거

항상 표시할 정보:

- 현재 `Zone · 시퀀스 · 스트로크 n/m`
- 전문가 기준 유사도와 숙련자 백분위
- 종합 판정과 평가 신뢰도
- 가장 중요한 교정 1건
- Zone 작업 순서와 선택 Zone 통계

접힌 상세 영역으로 이동할 정보:

- 나머지 교정 목록
- 부위별 편차와 원시 관절 데이터
- 기준 선정 근거
- 예상 개선 점수와 숙련자 집단 비교
- 입력 품질, 좌표계, 리샘플링 등 연구용 정보

제거할 중복 UI:

- 자세 비교/도장 경로 탭
- 자세 전용 재생 버튼과 타임라인
- 같은 의미의 작업자·레벨·기록 선택기 중복
- 중앙과 우측에 반복 표시되는 범례·현재 위치 텍스트
- 값이 없는 상태에서 임의로 `1 스트로크`를 표시하는 대체값

## 8. Zone과 전문가 기준

시퀀스의 프레임별 Zone ID를 시간순 연속 구간으로 보존한다. 한 시퀀스가 여러 Zone을 지나면 다수결로 하나로 합치지 않는다. Zone별 통계는 공식 시퀀스/스트로크 결과를 집계하며 Zone 자체를 하나의 가상 입력으로 재채점하지 않는다.

Zone별로 평가 가능 수, 제외 수, 유사도 중앙값, 최저 시퀀스, 반복된 핵심 교정을 표시한다. Zone을 선택하면 재생을 멈추고 해당 구간과 통계를 강조하며, 재생을 다시 시작하면 공통 playhead를 따라 현재 Zone 표시로 복귀한다.

전문가 자세는 엔진의 기준 선정 결과 또는 pose_lab의 동일 기준 선택 경로에서 가져온다. 운영 엔진 응답에 없는 `reference_layer`를 테스트용으로 임의 가정하지 않는다. 전문가 기준 좌표와 작업자 월드 좌표가 호환되지 않으면 겹치지 않고, 같은 3D 화면 내부의 별도 기준 인셋으로 표시하며 이유를 명시한다.

## 9. 모델과 성능 안전장치

- `alignment_status == verified`인 모델만 표시한다.
- 모드 2, 파일 누락, 파싱 실패는 Ray Point 표면으로 대체한다.
- 메시 정점·삼각형과 자세 프레임은 서버에서 상한을 적용한다.
- 평가 결과와 전문가 기준 선택은 세션/시퀀스 키로 캐시하되 새 시퀀스가 추가되면 세션 요약 캐시를 무효화한다.
- 긴 기록은 시간 기반 다운샘플링을 사용하고 교정 근거 프레임과 첫·마지막 프레임을 반드시 남긴다.
- 자세 엔진 실패는 기존 전문가 모션·도장 경로 재생을 중단시키지 않는다.

## 10. 반응형 배치

넓은 화면은 왼쪽 선택/재생, 중앙 3D, 오른쪽 평가 패널의 3열 구조를 사용한다. 1200px 이하에서는 평가 패널을 숨기지 않고 중앙 3D 아래로 배치한다. 720px 이하에서는 선택 패널, 3D, 평가 패널 순으로 세로 배치한다.

## 11. 검증 기준

- 김미진 선임 최신 브랜치가 병합되고 기존 Co-Pilot API 회귀가 없다.
- 전형기 모드와 CSV 선택 흐름이 유지된다.
- 작업자·레벨·세션·시퀀스 선택이 같은 화면에서 가능하다.
- 탭 없이 도장 경로, 작업자 자세, 전문가 자세, 핵심 교정이 동기 재생된다.
- 화면 결과와 Query API `pose_recomm`의 점수·교정이 일치한다.
- 객체가 원점에서 멀어도 객체 중심으로 회전하며, pan/dolly/fly와 홈·축 기즈모가 동작한다.
- 긴 기록에서도 재생이 끊기지 않고 비동기 선택 변경이 오래된 결과를 표시하지 않는다.
- mode 2와 모델 누락 시 정직한 대체 표면을 표시한다.
- 1200px 이하에서도 평가 패널이 보인다.
- 실제 브라우저에서 대표 전문가 CSV와 실제 TSB 세션을 각각 선택해 검증한다.

## 12. 완료 조건

사용자가 기존 모션뷰어의 방식으로 훈련모드와 기록을 선택하고 재생했을 때, 하나의 3D 화면에서 피도면·Zone·도장 경로와 작업자/전문가 자세 비교 및 핵심 교정을 동시에 이해할 수 있다. 모든 레이어는 하나의 시간축과 카메라를 공유하며, 객체 중심 회전과 Unity식 자유 이동으로 어느 위치의 모델도 자연스럽게 관찰할 수 있어야 한다.

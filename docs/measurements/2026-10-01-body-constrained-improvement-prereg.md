# 사전등록 — 몸 제약 개선율, 전수 (2차년도 정책)

작성 2026-10-01 · 측정 전에 커밋한다 · 스크립트 `trainer/scripts/body_constrained_study.py`
3차년도 정책(P2)은 `docs/year3/2026-10-01-body-constrained-prereg.md`에 따로 등록한다.

## 1. 왜 다시 재나

사용자 지적(2026-10-01): 교정 시연에서 몸이 늘어나고 발이 뜨는 문제를 고치고 나니 "이 논리에 의하면 기존 개선 점수
계산도 이상할 것", "모든 데이터 다시 측정해서 개선율을 다시 계산해줘."

기존 개선율은 채점하는 중요 조인트를 **서로 독립으로** 안내한 만큼 옮긴다.
- 팔 길이 제약이 없다 — 몸이 일어서도 손은 안내한 곳에 있다고 본다.
- 안내가 없는 점은 제자리다 — 몸이 옮겨 서거나 일어서도 왼손은 벽 기준 같은 자리라고 본다.
- 머리를 다리 길이 이상으로 올리라는 안내도 그대로 따랐다고 본다.

## 2. 정의

| 항목 | 값 |
|---|---|
| 쌍·표본 | 2차년도 전수와 같다 — 색인 64,098 패스 전부, 기준은 화면의 첫 기준(`screen_first`), 산포 `/output/spread_reference_expert_m3.json`, 색인 `/output/samelevel/index_cache_m3.json` |
| 정책 | `issued` 교정 알고리즘 안내 전부(관절 값 ≤4, KPI 정의), `delivered` 작업자에게 전달되는 1건 |
| 점 독립(기존) | `service.compare`가 내는 개선율 그대로 |
| 몸 제약(새) | 작업자의 대표 순간 골격(8130 3D 뷰와 같은 몸, 다리는 추정)에 교정을 `correction_demo.corrected_body`로 실현한다: 손은 팔 길이·쇄골 길이를 지키고(어깨 회전 ≤35°), 옮겨 서기는 몸 전체(안내 없는 손 포함), 자세 높이기·낮추기는 발을 디딘 채 다리가 다 펴지거나 접히는 데서 멈춘다. 그 몸에서 중요 조인트가 **실제로 움직인 양**만큼 궤적을 평행 이동하고 같은 채점기로 다시 잰다 |
| same / split | 기존과 같다 — split은 A 반쪽 산포로 교정을 고르고 B 반쪽으로 채점 |
| 정확도 | 개선율 (S1 − S0)/(1 − S0)의 평균 × 100 |
| 견주는 모집단 | 골격이 있고 두 값이 다 있는 쌍. 골격이 없는 쌍 수를 따로 낸다 |
| 함께 내는 것 | 몸 제약 − 점 독립 차이(평균·사분위), 몸 제약이 더 낮은 쌍 비율, 손(팔 길이)·머리(발 디딤)로 못 미친 거리, 작업자별 |

재현 검사(측정 전 고정, `trainer/scripts/tests/test_body_constrained_study.py`): 팔이 닿고 머리 안내가 없으면 몸 제약
실현이 점 독립 실현과 같다.

## 3. 판정

- **2차년도 KPI를 몸 제약으로도 주장할 수 있는가**: `issued` 몸 제약 split 정확도 평균 ≥ 70%.
- 점 독립 값(85.9%)은 그대로 두고 몸 제약 값을 나란히 싣는다. 어느 쪽을 공식으로 쓸지는 결과를 본 뒤 사용자가 정한다 —
  여기서 바꾸지 않는다.

## 4. 이 측정이 재지 못하는 것

- 몸은 패스의 대표 순간 하나다(채점은 패스 평균). 순간마다 팔이 닿는지는 다를 수 있다.
- 장비의 이동을 해당 조인트의 이동으로 대신하고 회전은 무시한다.
- 다리는 추정 골격이다. 숙련자 대 숙련자, 계산상 예상값이다.

## 5. 예측 (측정 전)

시간 재기로 20쌍을 돌렸고 상태(ok 18, 기준 없음 2)와 시간만 보았다. 예시 6쌍 어림(점 독립 대비 −0.8 … +6.1%p, 대부분 위)을 본
뒤의 예측임을 밝힌다.

- `issued` 몸 제약 split 평균 **87%**(84–90%), 점 독립보다 약간 높다 — 옮겨 서기에서 왼손이 몸을 따라가는 이득이 팔 길이 손해보다 크다.
- `delivered` 몸 제약 split 평균 **33%**(29–38%).
- 머리가 발 디딤으로 1cm 이상 못 미치는 쌍 **10%**(3–25%), 손이 팔 길이로 1cm 이상 못 미치는 쌍 **5%**(1–15%) — `issued` 기준.
- 골격이 없는 쌍 < 1%.

## 6. 추가 (측정 **후**, 2026-10-01) — 사후 민감도 분석

주 측정(위 정의, 안내 없는 손은 몸을 따라감 `follow`)을 본 뒤에 정했다. 전달 1건에서 24%의 쌍이 교정 전보다 나빠졌고,
그 하락은 팔 길이·발 디딤 부족이 아니라 "옮겨 서세요" 한 건에 안내 없는 손(건)이 몸을 따라 함께 옮겨 간 데서 나왔다.
안내 없는 손의 움직임은 측정이 정할 수 없는 가정이므로, 반대 가정 `stay`(안내 없는 손은 벽 기준 원래 자리를 지키고, 팔이
닿지 않으면 닿는 데까지만)로 같은 전수를 한 번 더 잰다(`--uncued-hands stay`, 산출 `/output/body_constrained_stay/`).
판정 기준은 바꾸지 않는다. 두 가정의 값을 함께 싣고, 어느 쪽을 쓸지는 사용자가 정한다.

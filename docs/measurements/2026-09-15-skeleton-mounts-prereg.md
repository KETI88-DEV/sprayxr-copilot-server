# 사전등록 — 스켈레톤 장착 상수(C_j, m_j)의 작업자 교차 검증

작성 2026-09-15. **이 문서는 `fit_skeleton_mounts.py`를 처음 실행하기 전에 커밋한다.**
커밋 순서(이 문서 → `trainer/pose_lab/skeleton_mounts.json`)는 git log로 확인한다.
여기 적힌 문턱은 결과를 본 뒤 옮기지 않는다. 불합격이면 폴백(§6)으로 가고 사후 완화하지 않는다.

## 1. 무엇을 검증하는가

화면 스켈레톤 배치(M6, `trainer/pose_lab/skeleton.place_oriented`)는 프레임마다

1. `A0 = Procrustes(Σ_j R_meas_j · C_jᵀ · W_jᵀ)` — 실측 강체 회전 `R_meas_j`(카메라/활성 건/플래쉬,
   `measured_pose` 규약 YXZ+)와 FK 관절 월드 회전 `W_j`(`pose_fk_csv`, YXZ+)에서 루트 회전을 푼다.
2. 중력 투영 `A = G·A0`, `G`는 `A0·ẑ_rig`를 `world_axes.UP`으로 보내는 최소 회전(리그 위 = +Z).
3. `target_j = marker_j − R_meas_j · m_j`, `t = mean_j(target_j − A·FK_j)`, `joints = A·p + t`.

로 놓는다. 여기서 `C_j`(관절↔강체 장착 회전)와 `m_j`(강체 로컬 장착 오프셋)는 상수다. 아바타 리그가
작업자 전원 같으므로(바인드 오프셋 차 0.0) 여러 세션을 합쳐 한 번 적합해 데이터 파일로 싣는다.
그 상수가 **적합에 쓰지 않은 작업자**에서도 일을 하는지를 잰다.

j ∈ {head(Head↔카메라), right(RightHand↔활성 건), left(LeftHand↔플래쉬)}. right는 건 그룹
(`한길숏건`/`한길폴건`/`반도숏건`/`반도폴건`)마다 따로 적합한다(강체 피벗이 건마다 다를 수 있다).

## 2. 표본

- 작업자 6명(`CsvPassSource.sessions()` — 학습모드 레벨 1..10만, `-A/-B/-C` 실전모드 제외).
- 작업자마다 세션 10개를 무작위로 뽑는다: `random.Random(20260915)`, 세션 목록을 (worker, date, level, session)
  순으로 정렬한 뒤 작업자별 `rng.sample(sessions, min(10, n))`.
- 세션마다 프레임: `measured_pose.measured_frames_with_rows`가 낸 프레임 중 분사 On이고 착탄점이 있는 것.
  균등 간격으로 최대 400개(`linspace` 인덱스). 관절 컬럼이 없거나 활성 건 회전이 없는 프레임은 뺀다.
- 왼손 앵커는 그 프레임에서 `frame.left`가 있고(거리 필터 통과) 플래쉬 회전이 있을 때만 쓴다.

## 3. 적합 절차(교대 최소제곱)

1. **회전 초기값**: 세션 s·앵커 j마다 상수 A 하나를 두고 40회 교대(`A = Proc(Σ_t R C ᵀ Wᵀ)`,
   `C = Proc(Σ_t Wᵀ Aᵀ R)`, 시작 C=I) → `C_{j,s}`. 초기 `C_j = Proc(Σ_s C_{j,s})`.
2. **회전 교대**: 20회. 프레임마다 `A0(t) = Proc(Σ_j R_j C_jᵀ W_jᵀ)`, 그다음 `C_j = Proc(Σ_t W_jᵀ A0(t)ᵀ R_j)`.
3. **오프셋**: 중력 투영한 `A(t)`로 앵커 쌍 차분식 `marker_a − marker_b − A(FK_a − FK_b) = R_a m_a − R_b m_b`를
   모든 프레임·쌍에 대해 선형 최소제곱(`numpy.linalg.lstsq`)으로 푼다. 미지수는 head·left·right[그룹]의 m.
4. `Proc`는 det+1 보정 SVD.

## 4. LOWO 폴드

- 폴드 k: 작업자 k의 세션을 뺀 5명 세션으로 §3 적합 → 작업자 k의 프레임에서 평가.
- 평가 세션의 건 그룹이 그 폴드 학습 세션에 3개 미만이면 그 세션은 평가에서 빼고 수를 보고한다.
- 평가 지표: 프레임마다 앵커 j의 miss = |(A·FK_j + t) + R_j·m_j − marker_j| (mm).
- **장착 없음 기준선**: 같은 폴드·같은 평가 프레임에서 `C_j = I`, `m_j = 0`으로 같은 배치(중력 투영 포함)를 해서 잰 miss.

## 5. 합격 기준(모두 충족해야 `passed = true`)

1. 앵커별(head/right/left) 평가 miss 풀링 중앙값 ≤ 150 mm, 그리고 폴드별·앵커별 중앙값 ≤ 200 mm.
2. 폴드별·앵커별로 장착 miss 중앙값 ≤ 0.7 × 같은 폴드 장착 없음 기준선 miss 중앙값(30% 이상 감소).
3. 모든 평가 프레임·`simulator_csv.BONES` 쌍에서 |배치 뼈 길이 − 바인드 오프셋 노름| ≤ 1e-9 m.

최종 상수는 60세션 전부로 §3을 한 번 더 돌린 값이다. 그룹 세션이 3개 미만이면 그 그룹 키는 싣지 않는다.
`passed = false`이면 `service`는 전역 상수를 쓰지 않는다.

## 6. 폴백(`mounts = "pass_fit_holdout"`)

전역이 불합격이거나 질의 패스의 건 그룹 키가 없으면: 질의 패스의 분사+착탄 프레임 중 대표 프레임
시각 ±1.0 s를 **뺀** 나머지(≥ 60 프레임)로 §3을 그 패스 하나에 돌리고 대표 프레임에서 잰다.
60 미만이면 스켈레톤을 싣지 않고 `fit_reason = "mounts_unavailable"`. 이때 miss는 "적합 잔차"로 표시한다.

## 7. 판정이 아닌 보고 항목

- `leg_tilt_deg`(골반→양발 중점 vs 월드 아래) 분포 — 중력 투영 뒤에는 FK 프레임 안의 값이라 C·m과
  무관하다. 데이터 성질로만 보고한다.
- `gravity_correction_deg`(투영 전 `A0·ẑ`와 UP 사이 각) 중앙값·p90.
- 건 그룹별 |m_right|(폴드별·최종).

## 8. 표시 규칙(게이트 아님, 사전등록)

- 파지 상한: 숏건 그룹 |m_right| ≤ 0.25 m, 폴건 그룹 ≤ 1.2 m. 넘으면 화면 notes에 "적합값이지 파지 거리가
  아니다" 고지를 싣는다. 검증 판정에는 쓰지 않는다.
- `faded`: `gravity_correction_deg > 20`. 진단 분포(중앙값 11.9°, p90 33.4°)를 **본 뒤** 정한 표시 문턱이다.

## 9. 이미 관측한 수치(이 문서 작성 전에 본 것 — 사전등록 대상 아님)

- 진단 M6(세션별 장착 적합: 앞 절반 적합·뒤 절반 평가, 6세션): 장착 보정 목표 대비 머리/오른손/왼손 miss
  중앙값 77/123/78 mm, 다리 기울기 13.7°(p90 20.4), 바닥 std 99 mm. 스크래치패드 sk_p9.py.
- 투영 전 A(t)의 리그 +Z 기울기 중앙값 11.9°, p90 33.4°.
- 세션별 건 오프셋 크기 0.60~0.77 m, 머리 0.10~0.35 m, 플래쉬 0.06~0.29 m (sk_p6.py).
- 대표 프레임 다리 기울기(옛 경로 기준 진단 인용): 김경호 L3 22.6°, L1 21.3°, 전형기 L8 16.7°.
- **아직 재지 않은 것**: 작업자 전체 풀링 상수의 LOWO miss, 장착 없음 기준선 miss. 이 둘이 §5의 대상이다.

# TSB 시뮬레이터 Query API 운영 기록 검증

2026-11-25 · v3.15.14 확인 · 교정판 v3.15.15

11월 3일 12:11부터 11월 25일 15:26까지의 기록을 조사했습니다. 호출 시각까지 수신된 훈련 시작·분사와 완료된 리포트를 기준으로 질문과 실제 답변을 대조했습니다. 현재 DB에 추가된 자료를 과거 질문의 근거로 사용하지 않았습니다.

| 조사 범위 | 호출 | 정상 | 부분 통과 | 오류 | 발화 확인 불가 | 음성 처리 실패 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| SIMULATOR/API 분류 | 171 | 74 | 58 | 32 | 3 | 4 |
| 출처 미기록, 이전 훈련 시작 연결 | 7 | 0 | 1 | 6 | 0 | 0 |
| 합계 | 178 | 74 | 59 | 38 | 3 | 4 |

출처 분류는 요청 헤더와 서버 규칙을 따른 표시입니다. 출처 미기록 7건은 같은 작업자·세션의 성공한 시작 호출을 확인했습니다. 나머지 출처 미기록 질의는 이 집계에서 제외했습니다. 텍스트와 인식 문장을 포함한 고유 질문은 33종이며, 가장 자주 등장한 작업 순서 질문은 141건입니다.

초기 버전은 분사가 시작되기 전 등록 기준 순서를 묻는 질문에 시퀀스나 리포트부터 요구했습니다. 또 이미 등록된 스프레이 세션에 블라스팅 순서를 함께 안내하던 기록이 있었습니다. 두 유형은 앞선 변경에서 교정이 확인되어 수정판에서도 기준 순서, 실제 순서, 공정 선택을 회귀 시험했습니다.

- 현재 문제가 무엇인지 물으면 최근 분사에서 확인한 도막과 진행 상태를 안내합니다. 전체 평가는 완료 리포트에서 별도로 확인합니다.
- 특정 구역 질문은 해당 구역의 평균과 분포를 답합니다. 어느 구역을 가리키는지 확인되지 않으면 번호를 다시 요청합니다.
- 목표 설정을 묻는 음성 발화는 세션 목표와 정상 범위를 사용합니다. 도막 검사 방법을 묻는 경우 시뮬레이터 히트맵과 실제 도막 측정의 근거를 구분합니다. [ISO 2808 도막 두께 측정](https://www.iso.org/standard/71583.html) · [ISO 19840 건도막 검사](https://www.iso.org/standard/59523.html)
- 완료 훈련의 궤적과 합격 개선 질문은 리포트의 실제 방문·권장 순서, 방향 평가, 저장된 시뮬레이터 결과를 사용합니다. 공식 합격선이 기록되지 않았으면 그 한계를 안내합니다.
- 음성 HTTP 실패 4건은 미인식 422 1건과 음성 인식 서비스 사용 불가 503 3건입니다. WAV 원본이 없어 불명확한 다른 발화 3건의 실제 질문을 판정할 수 없습니다.

합성 세션의 API 재시험 33건 중 33건 통과했습니다. 재현은 처음부터 같은 구조로 만든 합성 세션을 사용했습니다. 운영 응답 원문은 보존하며, 교정 예시는 실제 데이터와 분리해 학습 후보로 정리했습니다. 가중치 재학습 단계는 실행하지 않았습니다.

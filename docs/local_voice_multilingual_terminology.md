# 도장 Co-Pilot 7개 언어 전문용어 대비표

- 작성일: 2026-10-06
- 범위: 사용자 확인 언어인 한국어·영어·중국어·베트남어·우즈벡어·미얀마어·네팔어.
- 상태: **검수용 초안 v0.1 — 운영 사용 불가.** 승인된 전문 번역이나 인증된 현지 표준 용어집이 아니다.
- 목적: 같은 기술 개념을 언어별로 고정한 후 ASR·번역을 평가한다. 구현 방향은 [음성·다국어 PRD](local_voice_multilingual_copilot_prd.md)를 따른다.

## 1. 작성 원칙과 근거

한국어 정의가 정본이며 영어는 개념 비교 기준이다. 중국어는 간체, 우즈벡어는 라틴 문자로 초안을 작성했다. 지역·문자·현장 용례는 추가 확인한다. 아래 외국어 표현은 **조사와 개념 대응에 기반한 작성자 제안**이며 언어별 도장 전문가·원어민 확인 전까지 모두 `draft`다. 특히 우즈벡어·미얀마어·네팔어는 공인 도장 용어 자료를 확보하지 못했으므로 설명식 후보를 표준 용어처럼 취급하지 않는다.

제조사 자료에서 중국어 `干膜厚度`, `湿膜厚度`, `无气喷涂` 용례와 베트남어 도막 두께 관련 용례를 확인했다. 이것이 표 전체의 전문 번역을 인증하지는 않는다. 문서의 특정 제품 수치·기준은 이 용어집에 옮기지 않는다. [Jotun 중국어 제품 자료](https://www.jotun.cn/cn-zh/products-and-services/products/Tankguard-Storage), [Jotun 중국어 시공 지침](https://jotundatasheetsprod.blob.core.windows.net/ags/AG%C2%A441048%C2%A4Hardtop%20WF%C2%A4Zho%C2%A4CN.pdf), [Jotun 베트남어 기술 자료](https://jotundatasheetsprod.blob.core.windows.net/tds/TDS%C2%A443902%C2%A4SteelMaster%201200HPE%C2%A4vi-VN%C2%A4VN.pdf)

## 4. 검수·승인 절차 — 구현/배포의 선행 조건

1. 각 ID의 한국어 정의를 도장 담당자가 승인한다. 산식·단위·각도 기준은 실제 API/엔진 정의와 연결한다.
2. 언어별 원어민과 도장 실무자가 후보를 검수한다. “전문 용어”와 “초보 작업자용 설명”을 구분하고 동의어·흔한 발음·금지 오역을 수집한다.
3. 단어뿐 아니라 실제 질의·답변·경고 문장에서 평가한다. 숫자와 부정문을 포함하고 안전 지시 T15/T16은 별도 엄격 검수한다.
4. `approved`가 된 항목만 운영 용어집과 평가 정답에 사용한다. `draft/rejected`는 자동 주입하지 않는다.
5. 담당자·승인일·출처·예문·변경 사유를 기록하고 용어집 버전을 고정한다. 그 버전으로 해당 언어의 ASR/번역을 평가한 뒤 배포한다.

|---|---|---|---|---|

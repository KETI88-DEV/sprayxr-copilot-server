# 도장 전문용어 현지 문서 대조표

2026-10-06, v0.2. 기존 v0.1의 작성자 번역 후보를 재검토했다. **문서에서 실제 표기를 찾은 항목만 용례 확인으로 표시한다.** 현지 문서 확인은 전문 번역가의 전체 문장 품질 승인과는 별개다. 현지 영어 문서가 존재하는 것을 그 국가 언어의 용어 근거로 삼지 않는다.

1차 평가 배포는 한국어·영어·중국어다. 베트남어는 아래 용어 근거를 확보했으나 실제 번역 실패가 재현돼 보류했다. 우즈벡어·미얀마어·네팔어의 전문 문서도 확인했지만 핵심 용어와 음성/번역의 종단 품질 근거가 충분하지 않아 활성화하지 않는다. 해당 국가를 모델이 영구적으로 지원할 수 없다는 판단은 아니다.

## 4. 1차 배포 용어집

`trainer/multilingual/glossary.json`에는 네 언어에서 확인된 T01/DFT와 T11/표면처리를 보관하며, 현재 활성화된 세 언어의 대응을 번역 프롬프트에 제공한다. 용어 사용을 디코딩으로 강제하는 구현은 아니다. 다른 용어는 공통 LLM이 번역하며 원문·근거를 보존한다. `source-attested`는 문서 확인 상태이며 전체 번역의 전문가 승인이나 안전 정확도 보장이 아니다. 이번 서비스는 지식 질의 평가용이고 자세 교정·작업 명령·안전 판정의 외국어 배포는 후속 문장 평가 대상이다.

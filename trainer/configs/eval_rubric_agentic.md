# Agentic 평가 루브릭

## 채점 기준 (5차원 × 0-2점 = 최대 10점)

### 1. tool_selection_accuracy (0-2)
- **2점**: 올바른 도구를 올바른 순서로 모두 선택함
- **1점**: 일부 도구 누락 또는 불필요한 도구가 추가됨
- **0점**: 완전히 잘못된 도구 선택이거나 도구를 사용하지 않음

### 2. parameter_correctness (0-2)
- **2점**: 모든 파라미터가 정확함 (값, 타입, 필수 필드)
- **1점**: 필수 파라미터는 맞으나 값 일부가 부정확함
- **0점**: 필수 파라미터 누락 또는 타입 오류가 있음

### 3. reasoning_depth (0-2)
- **2점**: 다단계 추론이며 각 단계의 근거와 논리 연결이 명확함
- **1점**: 추론 과정은 있으나 단계가 부족하거나 근거가 약함
- **0점**: 추론 없이 결론만 제시함

### 4. context_integration (0-2)
- **2점**: MCP 결과와 문서 근거(예: chunk ID, 규정값)를 함께 통합함
- **1점**: context 일부만 활용함 (도구 결과 또는 문서 근거 중 한쪽만 활용)
- **0점**: 주어진 context를 거의 반영하지 않음

### 5. response_structure (0-2)
- **2점**: 요구 형식 준수 (예: XR JSON 스키마, 단계형 응답, citation 포함)
- **1점**: 부분적으로만 구조화되어 있음
- **0점**: 비구조적 텍스트로 핵심 요구 형식을 충족하지 못함

## 총점 해석
| 점수 범위 | 등급 | 설명 |
|---|---|---|
| 9-10점 | 우수 | 도구 사용, 추론, 구조화가 모두 안정적임 |
| 7-8점 | 양호 | 전반적으로 적절하나 일부 보완 필요 |
| 5-6점 | 보통 | 최소 요건은 충족하지만 일관성이 부족함 |
| 3-4점 | 미흡 | 도구/추론/구조 중 하나 이상이 크게 부족함 |
| 0-2점 | 부적합 | 과제 요구사항을 충족하지 못함 |

# 향후 로드맵

## 목표
Tool Calling + MCP 기반 코팅 훈련 에이전트를 단계적으로 확장하여 VLM 분석, 규칙 엔진, 음성/대시보드/운영 배포까지 연결한다.

## Week 2: VLM 통합
- 모델: `Qwen2-VL-2B-Instruct` 기반 히트맵 분석 파이프라인 연결
- 범위: `vlm_analysis` 스텁을 실제 추론 호출로 대체, ROI/이상영역/도막 분포 추정 고도화
- 산출물: MCP 응답 정확도 검증 리포트, 추론 지연 시간 벤치마크, 실패 케이스 분류표
- 하드웨어 요구사항:
  - 권장: RTX 4080 16GB (타깃)
  - 최소 개발: RTX 4070 Ti 12GB + 양자화(4bit) + 배치 제한
  - CPU/RAM: 8코어 이상, 32GB RAM

## Week 3: Rule Engine 통합
- 범위: motion/thickness/sequence scoring을 통합 계약(`rule_engine_interface.md`) 기반으로 연결
- 구현: RealCOAT 계산값 수신 -> 표준 점수 스키마 변환 -> 에이전트 피드백 생성
- 산출물: 점수 일관성 검증(RealCOAT vs Agent), 세션 리포트 자동 생성
- 하드웨어 요구사항:
  - 권장: RTX 4080 16GB (타깃, VLM 동시 실행 여유)
  - 최소 개발: GPU 없이 CPU 실행 가능(규칙 엔진 자체), 단 VLM 병행 시 GPU 필요
  - CPU/RAM: 8코어 이상, 32GB RAM

## Week 4+: 음성 인터페이스, UI 대시보드, 운영 배포
- 음성 인터페이스: 실시간 코칭 TTS/STT 연동, 세션 중 피드백 스트리밍
- UI 대시보드: 세션 히스토리, 점수 추이, 영역별 이상 분포 시각화
- 운영 배포: 컨테이너 기반 서비스화, 모니터링/알림, 버전 롤백 전략
- 하드웨어 요구사항:
  - 단일 노드 권장: RTX 4080 16GB, 64GB RAM, NVMe 1TB+
  - 확장 배포: API 서버/추론 서버 분리, GPU 노드 오토스케일 고려

## 리스크 및 대응
- VLM 추론 지연: 프롬프트/입력 해상도 최적화, 캐시 적용
- 데이터 포맷 드리프트: `session_summary.json` 버전 필드 기반 호환 레이어 유지
- 운영 복잡도 증가: 단계별 CI 검증, MCP 헬스체크 및 장애 격리 정책 강화
